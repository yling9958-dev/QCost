# Paper-Eval Redundancy Audit

| Area | Evidence | Decision |
|---|---|---|
| Dataset IDs, hashes and counts | Previously hard-coded in `run.py`; paths/methods in `support.py` | MERGED into `paper_protocol.py` |
| Timeouts | Previously `phase_timeouts.py`, `run.PROTOCOL`, call sites | MERGED; shim deleted; infrastructure-only normalize/load defaults remain distinct |
| Memory policy | Previously repeated in `run.py`, `cgroup_policy.py`, messages/tests | MERGED values; kernel operations remain in cgroup module |
| Method order/persistence | Previously `support.py`; GeoLife retry had separate ORDER/KEEP | MERGED formal order; retry selection is derived data |
| Status taxonomy | `outcomes.py` plus string literals in controller/report/tests | MERGED terminal constants; classifier remains separate |
| User entry points | main runner plus direct repair and historical unit names | MERGED CLI; repair module retained as internal engine |
| Result parsing/ranking | Centralized in `report.py` | KEEP |
| Resource monitoring | Centralized in `orchestrate.monitor` | KEEP |
| `finish_repair.py` | Not imported by main runner; only old handoff tests referenced it; no unit loaded | ARCHIVED; explicit `--resume` replaces automatic forward start |
| `diagnose.py` | Called by repair and monitor evidence | KEEP |
| `scripts/full_eval` | README says historical fixtures; exact-source test references files | TEST_ONLY; do not delete |
| `scripts/diagnostics` | Current 8-core and memory engineering evidence | KEEP outside formal path |
| r1/r2/r5 unit names | Runtime evidence, not source-level scientific state | ARCHIVE provenance; do not encode in new CLI |
| source-amendment compatibility gates | Needed to validate dirty historical campaign | KEPT; 20260914 receipt additionally binds source, tests and exact 100 MiB evidence |
| tracked `paper_eval/__pycache__` | No import or runtime dependency; regenerated by Python | DELETE_SAFE; eight tracked files removed, remaining cache quarantined |

No file is deleted solely because its name appears historical. Current imports,
tests, subprocess references, dynamic imports, and result dependencies are
checked in `DEAD_CODE_EVIDENCE.csv`.

The public workflow is now one shell entry with one protocol source. Campaign
and targeted repair retain separate internal service bodies because their
checkpoint ownership differs; users no longer need versioned r2/r3/r4/r5 unit
commands or a direct repair script.
