# GeoLife Dataset License Audit

Classification: **REDISTRIBUTION_RESTRICTED**

Dataset: Microsoft Research Asia GeoLife GPS Trajectories, version 1.3
(August 2012). Upstream project and download information:

- https://www.microsoft.com/en-us/research/project/geolife-building-social-networks-using-human-location-history/tools/
- https://www.microsoft.com/en-us/research/publication/geolife-gps-trajectory-dataset-user-guide/

The Microsoft Research License Agreement embedded in the official GeoLife user
guide permits non-commercial purposes such as academic research, teaching,
public demonstrations, and personal experimentation. It also states that the
software/data and derivative works may not be distributed in any form. The
frozen `geolife_100m.csv` is a derived selection and transformation of that
data, so it is excluded from the PUBLIC package. This audit is conservative and
is not legal advice.

The user's existing frozen copy is retained only in the INTERNAL FULL package
for the user's own research reproduction. Public users must obtain the official
archive from Microsoft, accept the upstream terms themselves, and run the
explicit package recovery procedure.

When using GeoLife, cite the papers requested by the upstream user guide:

1. Yu Zheng, Lizhu Zhang, Xing Xie, and Wei-Ying Ma. "Mining Interesting
   Locations and Travel Sequences from GPS Trajectories." WWW 2009.
2. Yu Zheng, Quannan Li, Yukun Chen, Xing Xie, and Wei-Ying Ma.
   "Understanding Mobility Based on GPS Data." UbiComp 2008.
3. Yu Zheng, Xing Xie, and Wei-Ying Ma. "GeoLife: A Collaborative Social
   Networking Service among User, Location and Trajectory." IEEE Data
   Engineering Bulletin 33(2), 2010.
